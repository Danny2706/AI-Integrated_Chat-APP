# AI Integrated Chat Application

An AI-powered real-time chat platform that combines modern messaging features with artificial intelligence capabilities. The application enables users to communicate in real time while leveraging AI assistance for enhanced conversations and productivity.

## Description

The AI Integrated Chat Application is a full-stack web application built to provide seamless communication through real-time messaging and AI-powered interactions. The project demonstrates modern software engineering practices, including frontend and backend integration, API communication, authentication workflows, and responsive user interface design.

This project was developed as part of my journey in learning full-stack software development and building scalable web applications.

## Installation

### Clone Repository

```bash
git clone https://github.com/Danny2706/ai-chat-app.git
cd ai-chat-app
```

### Install Dependencies

Frontend:

```bash
npm install
```

Backend:

```bash
npm install
```

### Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

### Run Development Server

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
